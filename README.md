# 飞机大战 (Plane Battle)

一个纯 HTML + Canvas 的飞机大战小游戏，无需任何构建步骤，直接打开 `index.html` 即可游玩。

## 玩法

- **方向键 / WASD**：控制飞机移动
- **自动开火**：无需按键，飞机会自动发射子弹
- **击败敌机**获得分数，不同颜色敌机分值不同
- **生命值为 0**时游戏结束

## 敌机种类

| 颜色 | 类型 | 生命值 | 分值 |
|------|------|--------|------|
| 红色 | 普通 | 1 | 10 |
| 橙色 | 重型 | 3 | 30 |
| 紫色 | 快速 | 1 | 20 |

## 难度递进

随着分数增加，敌机出现频率和速度都会提升，分数达到 200 后还会解锁侧翼火力。
